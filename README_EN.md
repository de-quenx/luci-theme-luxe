**Luci-Theme-LuxeOs** is a modern HTML5 theme for OpenWrt that supports **Auto Light & Dark Mode**. It offers various style options: elegant, luxurious, soft, with a collection of useful features for a smooth and intuitive user experience.

---

## **MAIN FEATURES / THEME STYLES**

- **Neumorphism**: Soft and elegant buttons and cards.  
- **Glassmorphism**: Transparent panels with light blur, smooth appearance.  
- **Glass 3D**: Adds depth to cards and panels for a modern look.  
- **Glass Dark**: Dark mode version of Glassmorphism, easy on the eyes.  
- **Neo-Brutalism**: Bold typography and solid colors to highlight key elements.  
- **Simple UI**: Minimalist layout, focused on content, easy to navigate.  
- **Neon UI**: Interactive elements with subtle glowing highlights.  
- **Crystal Glass**: Transparent crystal-like panels with soft light reflections.  
- **RGB Accent**: Subtle RGB color accents to highlight interactive elements.

## Installation

1. **Download Package**:

   - OpenWrt (IPK):
     ```bash
     opkg install luci-theme-luxe*.ipk
     ```
   - SNAPSHOT (APK):
     ```bash
     apk add luci-theme-luxe*.apk
     ```

2. **Activate Theme**:

   - Go to LuCI → System → System → Language and Style.  
   - Select **Luxe** from the Design Theme dropdown.

3. Done! The theme is now active.
